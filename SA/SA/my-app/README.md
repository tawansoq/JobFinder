# Manpower – Recruitment & HR Management System

1. `npm install`
2. ดับเบิลคลิก `start-docker.bat` (หรือ `docker compose up -d`) เพื่อเปิด PostgreSQL
3. `npm run dev` → เปิด http://localhost:5173 (API ที่ http://localhost:5000/api/health)

รีเซ็ตฐานข้อมูล: `docker compose down -v` แล้ว `docker compose up -d`
